# Honch

**Product analytics for the hardware you ship.**

Funnels, cohorts, retention, and feature adoption — for connected devices, not browser tabs.

---

## What is this

Honch is a product analytics platform built for connected consumer hardware. Drop our SDK into your firmware or companion app, and your product team gets the same kind of analytics web teams have had for fifteen years — without building a telemetry pipeline, running a data warehouse, or hiring a data team.

Hardware ships, then disappears. We fix that.

## SDKs

### Device

- **ESP-IDF** — Espressif ESP32 family
- **Zephyr** — Nordic, NXP, Silicon Labs, ST
- **Arduino** — Arduino IDE and PlatformIO
- **Embedded Linux** — Yocto, Buildroot, Raspberry Pi
- **Bare-metal C** — portable C99
- **Rust embedded** — `no_std`, Cortex-M and RISC-V
- **MicroPython / CircuitPython**

### App

- **iOS** — Swift
- **Android** — Kotlin
- **React Native**
- **Flutter**

### Module

- **Module Host SDK** — for customers using our drop-in cellular module
